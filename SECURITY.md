# Security Policy

## Reporting a vulnerability

If you discover a security issue, please do not open a public issue first.

Report vulnerabilities through
[GitHub Security Advisories](https://github.com/forkadarshp/MPort/security/advisories/new)
so the report stays private until a fix is ready.

Include:

- Description of the issue
- Affected files/paths
- Reproduction steps
- Suggested mitigation if available

We will acknowledge receipt and work on a fix as quickly as possible.

## Scope

This repository mainly contains skill instructions and documentation, but
security-sensitive patterns can still affect downstream automation. Please
report anything that could lead to unsafe or destructive behavior.
